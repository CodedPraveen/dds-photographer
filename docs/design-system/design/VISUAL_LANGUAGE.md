# Purpose

This document defines the visual language of the Photographer Business Website.

While **Design Principles** explain *why* we design a certain way, this document explains *how the interface should look.*

Every page, section, and component must follow these visual rules to maintain a consistent identity across the entire website.

---

# Vision

The website should feel like a premium photography exhibition rather than a traditional business website.

Every visual element should quietly support the photographs without becoming the center of attention.

The interface should communicate:

- Luxury
- Simplicity
- Professionalism
- Trust
- Editorial Quality
- Timeless Design

---

# Visual Identity

The overall appearance should be:

- Minimal
- Clean
- Spacious
- Elegant
- Modern
- Editorial
- High Contrast
- Image Focused

Nothing should feel overly decorative.

---

# Design Inspiration

Our visual language is inspired by:

- Leica
- Apple
- Sony Alpha
- Canon
- Awwwards
- Luxury Magazine Layouts
- Photography Exhibition Catalogs
- Minimal Editorial Websites

These are references for quality—not templates to copy.

---

# Photography First

Photography is the primary visual element.

Everything else exists to support it.

The hierarchy should always be:

```

Photography
↓

Typography

↓

Layout

↓

Interaction

↓

Decoration

```

---

# Layout Philosophy

Layouts should feel balanced and effortless.

Characteristics:

- Large breathing space
- Strong alignment
- Predictable spacing
- Clear reading flow
- Minimal distractions

Never overcrowd a section.

---

# White Space

White space is intentional.

It creates rhythm, elegance, and focus.

Never reduce spacing simply to fit more content.

Large empty areas are encouraged when they improve readability.

---

# Visual Hierarchy

Users should naturally know where to look.

Hierarchy should be established through:

- Size
- Position
- Contrast
- Spacing
- Image Scale

Avoid using excessive colors to create hierarchy.

---

# Color Language

The color palette should remain restrained.

Primary Colors

- Pure Black
- Pure White

Secondary Colors

- Soft Gray
- Neutral Gray

Accent Colors

- Warm Gold (very limited)
- Muted Beige (optional)

Bright colors should never dominate the interface.

Photography should remain the most colorful element.

---

# Contrast

Maintain strong readability.

Text should always remain readable against its background.

Avoid:

- Low contrast text
- Busy image backgrounds
- Decorative overlays that reduce readability

---

# Typography

Typography should feel modern and confident.

Characteristics:

- Large headlines
- Short paragraphs
- Clear hierarchy
- Comfortable spacing

Typography should support the photography rather than compete with it.

---

# Images

Images are the most important design asset.

Images should be:

- High quality
- Sharp
- Properly cropped
- Responsive
- Optimized
- Consistent

Never stretch or distort photographs.

---

# Composition

Every screen should feel balanced.

Follow these principles:

- Visual balance
- Consistent alignment
- Predictable spacing
- Strong focal points

Avoid visual clutter.

---

# Grid System

The layout should follow a consistent grid.

Goals:

- Consistent alignment
- Easy scalability
- Responsive behavior
- Predictable spacing

No section should appear disconnected from the overall layout.

---

# Shape Language

Use simple geometric shapes.

Preferred:

- Soft rounded corners
- Straight edges
- Clean rectangles
- Subtle curves

Avoid decorative or irregular shapes.

---

# Shadows

Shadows should remain subtle.

Purpose:

- Separate layers
- Create depth
- Improve readability

Never use exaggerated shadows.

---

# Borders

Borders should be minimal.

Use borders only when they improve clarity.

Avoid unnecessary outlines around every component.

---

# Icons

Icons should be:

- Minimal
- Consistent
- Functional
- Easy to recognize

Avoid decorative icon sets.

Every icon should communicate information.

---

# Buttons

Buttons should feel calm and confident.

Characteristics:

- Simple
- Easy to identify
- Comfortable spacing
- Clear hierarchy

Avoid oversized or flashy buttons.

---

# Cards

Cards should not feel heavy.

They should create organization without dominating the page.

Avoid:

- Thick borders
- Heavy shadows
- Excessive decoration

---

# Section Rhythm

Every section should have breathing room.

Maintain consistent vertical spacing throughout the website.

Visitors should naturally understand when one section ends and another begins.

---

# Visual Consistency

Every component should look like it belongs to the same product.

Consistency includes:

- Radius
- Shadows
- Spacing
- Typography
- Colors
- Alignment

Never redesign components independently.

---

# Responsive Design

The visual language must remain consistent across:

- Mobile
- Tablet
- Laptop
- Desktop
- Large Displays

Layouts may adapt.

Identity should not change.

---

# Motion Relationship

Motion supports the visual language.

Motion should:

- Guide attention
- Reveal information
- Improve storytelling

Motion should never become decoration.

Detailed motion rules are documented in:

`MOTION_GUIDELINES.md`

---

# Accessibility

Visual beauty should never reduce usability.

Requirements:

- Readable typography
- Proper contrast
- Clear focus states
- Large touch targets
- Responsive scaling

Accessibility is part of the visual language.

---

# Consistency Checklist

Before approving any design, verify:

- Does it match the established visual identity?
- Does it prioritize photography?
- Is spacing consistent?
- Is typography consistent?
- Is the layout balanced?
- Is contrast sufficient?
- Does it remain minimal?
- Does it improve the user experience?

If any answer is **No**, the design should be revised.

---

# Things We Avoid

The project intentionally avoids:

- Glassmorphism
- Neon colors
- Heavy gradients
- Excessive blur
- Large decorative shadows
- Busy backgrounds
- Random color usage
- Inconsistent spacing
- Trend-based UI
- Over-designed layouts

---

# Success Criteria

The visual language is successful when:

- Photography remains the primary focus.
- Every page feels connected.
- The interface disappears behind the content.
- Users feel they are exploring a premium photography experience.
- The design remains timeless rather than trendy.

---

# Guiding Question

Before introducing any new visual element, ask:

> Does this improve the photography experience without distracting from it?

If not, it should not be added.
