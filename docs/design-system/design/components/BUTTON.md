# Premium Button Design

The button system follows a **minimal editorial design language**, emphasizing elegance, confidence, and subtle interaction rather than loud calls-to-action.

Buttons should naturally guide visitors through the experience while allowing the photography to remain the primary focus.

Every button should feel tactile, refined, and effortless to interact with.

---

## Primary Button

```text
╭──────────────────────────╮
│     View Portfolio       │
╰──────────────────────────╯
```

The primary button represents the main action within a section.

Examples include:

- View Portfolio
- Explore Collection
- View Gallery

Only one primary button should exist within a visual group.

---

## Secondary Button

```text
View Portfolio →
```

or

```text
○ Learn More
```

Secondary buttons support navigation without competing with the primary action.

They remain lightweight and visually quiet.

---

## Ghost Button

Ghost buttons contain no visible background until interaction.

```text
Contact

────────
```

or

```text
Contact →
```

These are used inside editorial layouts where visual simplicity is preferred.

---

## Initial State

When first displayed:

- Minimal appearance
- Comfortable padding
- Medium typography
- Soft rounded corners
- Premium spacing
- Calm visual weight

Buttons should integrate naturally into the layout.

---

## Hover Interaction

Hover should communicate interactivity without becoming distracting.

Changes include:

- Slight background transition
- Gentle brightness increase
- Thin border refinement
- Soft elevation (optional)
- Cursor changes to pointer

Large scaling or exaggerated animations should be avoided.

---

## Active State

When pressed:

- Slight downward movement
- Small scale reduction (≈0.98)
- Immediate response

The interaction should feel natural and tactile.

---

## Focus State

Keyboard navigation should remain fully accessible.

Focus styling should include:

- Visible outline
- High contrast
- Consistent appearance

Focus indicators should never be removed.

---

## Loading State

While processing an action:

```text
╭──────────────────────────╮
│        Loading...        │
╰──────────────────────────╯
```

or

```text
╭──────────────────────────╮
│       ○ Loading          │
╰──────────────────────────╯
```

The button width should remain fixed to prevent layout shifts.

Interaction should be disabled until completion.

---

## Disabled State

Disabled buttons should clearly communicate their state.

Characteristics:

- Lower opacity
- Reduced contrast
- No hover interaction
- No pointer cursor

Disabled actions should remain visible instead of disappearing.

---

## Typography

Buttons use the primary UI font.

Characteristics:

- Medium weight
- Comfortable letter spacing
- Sentence case
- Excellent readability

Avoid:

- ALL CAPS
- Decorative fonts
- Heavy bold weights

Typography should feel calm and premium.

---

## Shape

Buttons use soft rounded corners.

Suggested appearance:

- Medium border radius
- Balanced proportions
- Comfortable padding

The shape should complement the overall editorial aesthetic.

---

## Border

Primary buttons may use:

- No border

or

- Thin subtle border

Secondary buttons may use:

- Thin outline

Borders should remain understated.

---

## Color

Buttons inherit colors from the global design system.

Typical appearance:

Primary

- High contrast background
- Clear readable text

Secondary

- Transparent background
- Thin border

Ghost

- Transparent
- Text only

Avoid introducing unique colors for individual buttons.

---

## Shadow

Buttons should use little or no shadow.

If elevation is needed:

- Very soft shadow
- Low opacity
- Minimal blur

Heavy shadows should never be used.

---

## Spacing

Buttons should have generous internal spacing.

Recommended proportions:

- Comfortable horizontal padding
- Balanced vertical padding
- Consistent spacing between adjacent buttons

Whitespace contributes to the premium feel.

---

## Icon Integration

Icons should remain secondary.

Examples:

```text
View Portfolio →

↓

← Back

↓

Download ↓
```

Icons should:

- Match text height
- Maintain equal spacing
- Animate subtly

Avoid oversized icons.

---

## Hero Buttons

Hero buttons should feel confident without dominating the screen.

Example:

```text
──────────────────────────────

      View Portfolio

──────────────────────────────
```

The Hero CTA should invite exploration rather than aggressively demand attention.

---

## Responsive Behavior

### Desktop

Buttons maintain their natural width based on content.

Spacing remains generous.

---

### Tablet

Padding decreases slightly while preserving proportions.

---

### Mobile

Buttons become easier to tap.

Characteristics:

- Larger touch area
- Comfortable spacing
- Optional full-width layout where appropriate

Minimum touch target:

44 × 44 px

---

## Animation

Buttons should animate smoothly.

Transitions include:

- Background fade
- Border transition
- Soft opacity changes
- Gentle elevation
- Small scale feedback

Recommended duration:

150–250ms

Animations should feel effortless.

---

## Accessibility

Buttons should:

- Support keyboard navigation
- Maintain visible focus states
- Meet contrast requirements
- Provide descriptive labels
- Be usable with screen readers

Accessibility should never be sacrificed for aesthetics.

---

## Design Principles

- Minimal
- Elegant
- Premium
- Calm interactions
- Comfortable spacing
- Excellent readability
- Consistent across the website

Buttons should quietly guide users through the experience while allowing the photography to remain the center of attention.
